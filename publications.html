M. V. Thanoshan, K. Banujan, B. Kumara, S. Prasanth, Z. Li, and I. Paik, "Code clone detection using boosting algorithms," in Proc. 2023 3rd Int. Conf. Advanced Research in Computing (ICARC), Belihuloya, Sri Lanka, Dec. 2023, pp. 244-249, doi: 10.1109/ICARC57651.2023.10145638.

This paper presents an innovative approach to code clone detection using ensemble learning methods. We demonstrate how boosting algorithms can significantly improve the accuracy of detecting similar code segments across large software repositories.
